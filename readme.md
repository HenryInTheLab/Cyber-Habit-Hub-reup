# CyberHabit Hubs

CyberHabit Hubs is a cybersecurity education platform developed as part of an industry-mentored postgraduate capstone project at Monash University. The platform was designed to help users build safer online habits through structured learning content, interactive activities, and role-based access to platform features.

The project received **Mentor’s Choice - Best Project**.

## Project Overview

CyberHabit Hubs focuses on improving cybersecurity awareness through a practical and user-friendly learning experience. The platform supports different user roles and provides access to cybersecurity learning resources, activities, and progress-related features.

My contribution focused on backend and security-related functionality, especially role-based access logic, feature testing, defect identification, system diagrams, and stakeholder presentation materials.

## Key Features

* Role-based access control for different user types
* Cybersecurity learning content and user guidance
* User authentication and access-related workflows
* Feature testing across multiple user roles
* Defect identification and issue resolution support
* System diagrams explaining user flows and access logic
* Stakeholder presentation materials for industry mentor review
